#  LiteBite – Food Delivery App

LiteBite is a modern and user-friendly food delivery mobile application developed using **Flutter and Dart**. It provides an attractive and responsive interface where users can explore food categories, discover popular dishes, search for their favourite food, manage favourites, and add items to their shopping cart.

The application is designed to provide a smooth and convenient food ordering experience with a clean UI, attractive food images, and easy navigation.

##  Features

-  **Home Screen** – Beautiful dashboard with special offers and popular dishes.
-  **Explore Categories** – Browse different food categories such as Lays, Kurkure, Chips, and Pizza.
-  **Food Search** – Search for your favourite food easily.
-  **Favourite Items** – Save your favourite food for quick access.
-  **Shopping Cart** – Add and manage food items in your cart.
-  **User Profile** – Access your personal profile.
-  **Modern UI** – Clean design with attractive colours, images, and smooth navigation.

##  Technologies Used

- Flutter
- Dart
- REST API Integration
- PHP Backend
- JSON Data Handling
- HTTP Package
